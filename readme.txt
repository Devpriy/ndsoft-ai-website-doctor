A user-friendly, safety-first WordPress diagnostic assistant.

== Description ==

Version 0.1.0 provides a zero-configuration, read-only health scanner and plain-language dashboard. It intentionally performs no automated fixes and sends no site data to an external AI service.

== Installation ==

1. Upload the plugin ZIP in Plugins > Add Plugin > Upload Plugin.
2. Activate NDsoft AI Website Doctor.
3. Open Website Doctor in wp-admin.
4. Click Scan My Website.
