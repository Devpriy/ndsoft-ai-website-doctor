# Roadmap

## v1.0.0 — Core product

- Diagnostics
- Local diagnosis
- Change tracking/history
- Support reports
- Low-risk maintenance
- Settings/privacy controls
- Authenticated read-only REST integration

## v1.1+

- Better issue-specific repair playbooks
- More compatibility intelligence
- Scan scheduling/notifications
- Agency-oriented multi-site workflows

## Pro / Cloud (separate service)

- Optional NDsoft cloud AI diagnosis with explicit consent and payload minimization
- Licensing and fair-use controls
- White-label reports
- Remote monitoring / agency dashboard
- MCP/agent workflows

The core plugin should remain useful without a cloud subscription.
