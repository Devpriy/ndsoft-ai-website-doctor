# Privacy

Core v1.0 is local-first.

Stored locally:

- latest scan result;
- scan timestamp;
- bounded scan history;
- plugin settings.

Not sent remotely by core v1.0:

- scan diagnostics;
- debug-log content;
- plugin/theme inventory;
- WordPress/PHP/database environment data.

Exported reports are created only when an administrator explicitly downloads or copies them.
